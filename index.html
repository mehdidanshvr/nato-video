NATO Video — نسخه آزمایشی 1) وارد github.com شو و یک repository جدید بساز؛ مثلاً nato-video (Public). 2) در repository گزینه Add file > Upload files را بزن و index.html را آپلود و Commit changes کن. 3) وارد Settings > Pages شو. 4) در Build and deployment گزینه Deploy from a branch را انتخاب کن. 5) Branch را روی main و folder را روی /(root) بگذار و Save کن. 6) چند دقیقه صبر کن تا آدرس GitHub Pages ظاهر شود. استفاده: - بخش «افزودن ویدئو» فقط لینک مستقیم فایل ویدئو را ذخیره می‌کند؛ خودش فایل را آپلود نمی‌کند. - برای پخش، لینک باید مستقیماً به فایل قابل‌دسترسی مثل MP4 برسد و سرور میزبان از پخش مرورگر پشتیبانی کند. - اطلاعات این نسخه فقط در localStorage همان مرورگر/دستگاه است؛ بین کاربران همگام نمی‌شود و پنل مدیریت امن نیست. - برای آپلود واقعی، حساب کاربری، مدیریت محتوا و ذخیره‌سازی عمومی/خصوصی، باید بک‌اند و فضای ذخیره‌سازی اضافه شود.
